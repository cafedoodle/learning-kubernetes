2.7 Spin up and explore a minikube cluster
minikube start

Next, let's create a cluster with minikube. The command is minikube start.
The difference between minikube and cube control.
The minikube command helps you create a cluster from scratch,
whereas cube control lets you interact with your cluster.
In the future, when you spin up a cluster using a cloud provider like AWS, Azure, or gcp, you'll use their command line tool to generate the cluster and cube control for the rest of your actions.
